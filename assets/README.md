# Pipeline Image Assets

Drop the following files here and the pipeline header/sidebar will automatically use them:

| Filename | Usage | Recommended size |
|---|---|---|
| `grp_logo.png` | GRP logo — shown in sidebar header and main page hero | 200 × 60 px, transparent background |
| `revlabs_hero.jpg` | Revolution Labs property photo — shown in main page hero banner | 1200 × 300 px |

Both files are optional. If absent, the header renders as styled text only.
